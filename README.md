## Setup

1. Clone the repo
```bash
   git clone https://github.com/kaurgurveend/portfolio-gurveender.git
```
2. Add your images to `assets/images/` (see folder guide below)
3. Open `index.html` in a browser

## Deploy to GitHub Pages

1. Go to repo **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` / `root`
4. Save — your site will be live at `https://kaurgurveend.github.io/portfolio-gurveender`
