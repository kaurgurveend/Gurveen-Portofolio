# Panduan Folder Gambar

## Struktur Folder
```
assets/
└── images/
    ├── profile/
    │   └── photo.jpg         ← foto profil kamu (bisa .jpg / .png)
    └── projects/
        ├── ais.jpg           ← screenshot project AIS
        ├── panen-in.jpg      ← screenshot Panen In
        ├── evently.jpg       ← screenshot Evently
        ├── age-calculator.jpg← screenshot Age Calculator
        ├── veen-moda.jpg     ← screenshot Veen Moda
        └── cinema-web.jpg    ← screenshot Cinema Web
```

## Cara Pakai
1. Taruh foto kamu di folder `profile/` dengan nama `photo.jpg`
2. Taruh screenshot project di folder `projects/` sesuai nama file di atas
3. Buka `index.html` di browser — gambar otomatis muncul!

## Tips Screenshot
- Ukuran ideal: 1200x700px atau lebih
- Format: JPG atau PNG
- Kalau nama file beda, edit bagian `src` di index.html
